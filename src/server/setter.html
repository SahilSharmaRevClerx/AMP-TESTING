Super Admin jwt

The setter logs in as a Super Admin to edit roles. The jwt stays in memory for this run only.

How do I get the jwt?
  1. Open an incognito window and log in to the site as a Super Admin.
  2. Press F12 → Application → Cookies → select the site.
  3. Copy the Value of the jwt cookie below. Pasting jwt=… also works.
