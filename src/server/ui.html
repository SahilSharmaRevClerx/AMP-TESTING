Which environment?

The AMP site to test. Use a QA or staging site, not production.

Choose the rulebook

A sheet with a page column and one Yes/No column per user type (e.g. site_admin, super_admin, normal_user).

OR

Who should we test as?

One row per user type in your rulebook. Paste the jwt cookie only for the ones you want to test; a row is ticked automatically. It stays in memory for this run only.

How do I get the jwt?
  1. Open an incognito window (one per user, so logins don't mix) and log in to the environment as that user.
  2. Press F12 → Application → Cookies → select the site.
  3. Copy the Value of the jwt cookie into that user's row. That's the only thing needed.
  4. The row names come from your rulebook and are only labels: the tool does not force a row to be that role. After checking, each row shows who the jwt really belongs to — make sure it matches.
  5. If one of the pasted jwts belongs to a Site Admin (with MFA), it is used automatically as the reference: it opens every page first, so the tool knows what each page looks like when it really opens. Recommended, not required.
