AMP Permission Testing

Checks which pages each user type can see and open, against your rulebook. Read-only: pages are only opened, never changed.

1Environment

The AMP site to test. Use a QA or staging environment, not production.

2Rulebook

A sheet with a page column (e.g. /#setup/roles or the full URL) and one Yes/No column per user type, e.g. site_admin, super_admin, normal_user. Those columns become the user types below. See rulebook/template.csv.

3Users & tokens

Paste the jwt and X-CSRF-Token cookies only for the user types you want to test; rows with tokens are ticked automatically, empty rows are skipped. Tokens are kept in memory for this run only and never saved.

How to copy the tokens
  1. Open an incognito/private window (one per user, so logins don't mix).
  2. Log in to the environment as that user.
  3. Press F12 → Application → Cookies → select the site.
  4. Copy the Value of jwt and of X-CSRF-Token into that user's row.
  5. The reference row is optional but recommended: a Site Admin with MFA enabled opens every page first, so the tool knows what each page looks like when it really opens. Without it, results are slightly less precise.
