Whose connections?

One row per account. Connections are per person, so a second account usually shows more. jwts stay in memory for this run only.

How do I get the jwt?
  1. Open an incognito window (one per account, so logins don't mix) and log in to the site as that account.
  2. Press F12 → Application → Cookies → select the site.
  3. Copy the Value of the jwt cookie into that account's row. Pasting jwt=… also works.
